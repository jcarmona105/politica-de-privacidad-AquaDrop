Política de Privacidad –  AquaDrop Analytics
Última actualización: (05/01/2026)

Esta Política de Privacidad describe cómo se maneja la información dentro de la aplicación Control de Riego QC (en adelante, “la App”), desarrollada por JIC Developer.

1. Información que recopila la App

La App permite registrar datos de evaluación de riego por goteo ingresados manualmente por el usuario, tales como:

Hacienda, lote y operador (si el usuario los diligencia).

Fecha de evaluación.

Presiones (antes, después y final).

Caudales medidos (Q1–Q9).

Resultados calculados (CU, DU), alertas y recomendaciones.

✅ La App no solicita registro de cuenta, no pide correo, ni contraseña.

2. Cómo se usa la información

La información ingresada se utiliza únicamente para:

Calcular indicadores de uniformidad (CU y DU).

Mostrar resultados, alertas y recomendaciones.

Guardar evaluaciones en el dispositivo para consulta posterior.

Exportar evaluaciones a un archivo Excel para que el usuario lo pueda ver o compartir.

3. Dónde se almacena la información

Los datos se almacenan localmente en el dispositivo usando una base de datos interna (SQLite).
La App no envía esta información a servidores externos.

4. Exportación de datos (Excel)

Cuando el usuario exporta la información, la App genera un archivo .xlsx en el almacenamiento del dispositivo.
El control del archivo y su uso (abrir, compartir, enviar por WhatsApp/correo, etc.) queda bajo responsabilidad del usuario.

5. Permisos del dispositivo

La App puede requerir permisos como:

Acceso a almacenamiento/archivos: para guardar y abrir el Excel exportado.

La App no usa permisos sensibles como ubicación, contactos, cámara o micrófono (a menos que tú los agregues en el futuro).

6. Servicios de terceros

Actualmente la App no integra servicios de terceros para analítica, publicidad o seguimiento (tracking).

7. Privacidad de menores

La App no está dirigida específicamente a menores. No se recopila intencionalmente información personal de niños.

8. Cambios a esta política

Esta Política puede actualizarse si se agregan nuevas funciones. Cualquier cambio se reflejará en esta misma página con una nueva fecha de actualización.
